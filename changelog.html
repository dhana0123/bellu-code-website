Changelog

What’s new in Bellu Code.

Shipped in November 2026, newest first.

Nov 27, 2026
Improved

Always-fresh threat data

  • Bellu Code uses the shared Bellu threat database, so your vulnerability data comes from one trusted source.
  • Updates to the database reach the app without manual work.
  • It runs on Windows as well, with safe handling of update files and disk space.
Nov 26, 2026
New

AI and cloud inventory

  • See every AI model, software package and cloud resource you rely on in one list (AI-BOM and Cloud-BOM).
  • Know what you're running before you decide what to secure.
  • Built-in AI rules flag risky AI setups.
Nov 26, 2026
New

Live protection

  • A runtime sensor watches for risky activity while your systems run.
  • Suspicious behavior is flagged as it happens.
  • Alerts show up in the same place as the rest of your security view.
Nov 26, 2026
Improved

More clouds

  • Scanning now works across multiple cloud providers, not just one.
  • Deeper checks cover who has access, how your network is set up, and where your data lives.
  • Everything feeds into the same security map.
Nov 25–26, 2026
Improved

Same experience on desktop and web

  • The desktop app and the web app now look and behave the same.
  • The desktop build issue is fixed.
  • You can switch between them without relearning anything.
Nov 25, 2026
New

First security scanners

  • The first built-in scanners check your projects for security problems.
  • This is the base for the upcoming secret and software inventory scans.
Nov 22, 2026
New

Know before you change code

  • Before editing, Bellu Code checks your code against known weaknesses.
  • It limits each plan to the 20 most important weaknesses so the output stays focused.
  • Edits are based on what is actually risky, not guesses.
Nov 22, 2026
New

See what's being exploited

  • See which vulnerabilities attackers are using right now.
  • See which weaknesses tend to be exploited together.
  • Use this to fix what matters first.
Nov 21–22, 2026
New

A knowledge base of known threats

  • It pulls from NVD, CISA KEV, EPSS, OSV, GitHub Advisories, MITRE ATT&CK, CAPEC and Exploit-DB.
  • Search any CVE and see what's connected to it, including related weaknesses, exploits and fixes.
  • Stats show how complete each source is.
Nov 14–15, 2026
New

See your security as a map

  • Your cloud, code and risks appear as one connected graph.
  • Follow how a weak spot in one place can lead to another.
  • Switch between views to focus on what you care about.
Nov 13, 2026
New

Connect your cloud

  • Link AWS and GitHub with read-only access.
  • Bellu Code can look at your setup but cannot change anything.
  • Setup takes a few clicks.
Nov 13, 2026
New

Security inside your sessions

  • A security menu on Home gives you one-click access to security tools.
  • Security panels open inside any coding session.
  • You don't need to leave your work to check security.
Nov 12–13, 2026
New

New look

  • New Bellu Code logo and icons.
  • Orange brand color for buttons, focus and selection.
  • A sharp, square design across the app.
  • Open sessions are tinted in their project color so they're easy to tell apart.
Nov 12–13, 2026
Fixed

Sign-in and speed fixes

  • Sign-in now shows the app's own screen instead of a browser prompt.
  • The web app loads correctly.
  • Icons and the app manifest update when they change.
