Changelog

What’s new in Bellu Code.

Detailed notes on new capabilities, improvements, fixes, and the work behind each release.

01 Nov 18, 2026
New

Voice conversations with agents

You can now talk with your agents in a real-time voice conversation. Describe a change out loud, ask what an agent is working on, and hear concise updates as work moves forward. Voice conversations are available wherever you work with Bellu Code.

Start a conversation

When an agent is idle, select the waveform button next to the input. Bellu Code starts a new voice session, while the existing chat history stays available for context.

Stay informed while work runs

Keep asking questions while an agent changes files or runs checks. Hear short progress notes, review the final answer, and jump into the written conversation at any time.

Voice and dictation

Voice conversations are separate from dictation. Dictation turns speech into text in the prompt; voice mode creates a two-way conversation with spoken agent replies.

02 Nov 4, 2026
Improved

Workspace-wide project search

Search now understands files, symbols, recent changes, and project conventions together, helping agents retrieve the context most likely to be useful.

More relevant results

Search ranks exact names, nearby definitions, referenced files, and active changes instead of returning a flat list of matching text.

Live workspace context

Agents receive a fresher view of newly added files, open changes, and recently edited symbols as a session progresses.

Quicker refinement

Results update as you narrow a query, making it easier to move from a broad concept to the exact symbol or file you need.

03 Oct 21, 2026
New

Custom project instructions

Create reusable instruction profiles for architecture rules, testing patterns, release conventions, and the tools each team uses.

Profiles for every workspace

Choose an instruction profile for a project or repository. Bellu Code applies the profile automatically to new chats and background tasks.

Clearer guardrails

Important constraints remain visible in the chat so you can review what the agent is following and adjust it before work begins.

Team consistency

Share the same project conventions across developers, agents, and long-running workflows without repeating instructions in every request.

04 Oct 8, 2026
Fixed

More reliable background tasks

Long-running tasks now provide clearer progress, preserve status across interruptions, and recover with more helpful resume and retry actions.

Better status updates

Tasks show the current stage, completed work, and next action instead of a single indeterminate progress indicator.

Safer recovery

After an interruption, review completed changes before continuing. Failed steps can be retried without repeating unrelated work.

Clearer failures

Error summaries identify the failed command or tool and include a direct next step when a task cannot continue automatically.
