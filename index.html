What subagents do you have access to?

I have four subagents:

  • explore: Fast codebase exploration. It finds files by pattern, searches code for keywords, and answers questions about how the code works.
  • general: A general-purpose agent for complex research and multi-step tasks. It can run several units of work in parallel.
  • seek: Looks up known CVEs and fix commits for weaknesses a task might introduce. I'd use it before writing or reviewing security-sensitive code.
  • translator: Translates content into a specified locale while keeping technical terms intact.

Why sources matter

Full context for every change

Your code is only part of the picture. Sources show Bellu Code where that code runs and who can reach it, so its fixes and risk scores match your real cloud and security posture.

Permissions

Read-only roles only

Each source asks for viewer access: Reader and Security Reader on Azure, Viewer on Google Cloud, the view role on Kubernetes, and read scopes on GitHub and GitLab.

Why it's safe

It can look, never change

Every request is checked against a read-only allowlist, so write calls are blocked. Credentials are short-lived, and secret values are never stored.
